# Antora (ASCIIDocs) Documentation

This is the repository for the https://test.docs.midokura.com[Test Documentation website]. It is built with https://antora.org[Antora].

## Install locally

Background: https://docs.antora.org/antora/2.3/install-and-run-quickstart[Install antora] with software dependencies.

```bash
# Install Node and Npm, for instance using nvm:
wget -qO- https://raw.githubusercontent.com/nvm-sh/nvm/v0.35.3/install.sh | bash
nvm install node

# If the antora installation succeeds, `antora -v` will return antora's version.

# Clone repository and build documentation website.
git clone https://github.com/midokura/documentation-opennms
cd documentation-opennms

# Install Antora and dependencies
npm install

# build the static site
npx antora antora-playbook.yml

# The generated website will be created under ```build/site/``` folder. Open ```index.html``` with any browser.
xdg-open build/site/index.html
```

## Allow private repos

By default Antora works with public repos; to make it work with a private repo you need to supply it with a Personal Access Token (PAT).

https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens#creating-a-personal-access-token-classic[Create your PAT]

https://docs.antora.org/antora/latest/playbook/private-repository-auth/#populate-credentials-interactively[Deploy your PAT]

```bash
git config --global credential.helper store && echo -n 'Repository URL: ' && read REPLY && git ls-remote -h $REPLY > /dev/null
```

You will be prompted for the URL of the private repository you want to use.

Now you can rebuild with the private repo.

```bash
# build the static site
npx antora antora-playbook.yml
```
